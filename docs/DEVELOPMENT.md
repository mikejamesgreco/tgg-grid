# Development Notes

`tgg-grid.html` is the application artifact.

The surrounding repository exists to document, demonstrate, test, and release that single-file application.

## Versioning

During development, preserve sequential build history in Git commits/tags rather than changing the canonical application filename.

## Definition of Done

A feature change should include:
- implementation
- embedded Help Center updates
- JavaScript syntax validation
- relevant regression fixture updates
- manual smoke testing for affected UI behavior
